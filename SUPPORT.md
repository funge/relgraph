# support

for help with relgraph, report a problem or ask a question in
[GitHub issues](https://github.com/funge/relgraph/issues).

for a bug report, include:

- app version and build number
- device and operating system version
- steps to reproduce the problem
- expected and actual results

for a graphing problem, a formula, view bounds and screenshot can help. mention
whether rendering was still running, paused or finished. share only examples you
are comfortable making public.

issues and comments are public. remove personal information, private graph
content and credentials before posting, including from screenshots and logs.

relgraph is developed by John Funge. see the [privacy policy](PRIVACY.md) for
information about local storage, sharing and support.
